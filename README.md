# Спрос — синхронизация рабочих программ с рынком труда

Система рекомендаций для актуализации рабочих программ дисциплин на основе анализа рынка труда.

## Технологии

- React 18 (UMD)
- Babel Standalone
- Vanilla CSS with CSS Variables

## Деплой

Сайт автоматически публикуется на GitHub Pages при пуше в `main` ветку.

## Локальная разработка

Просто откройте `index.html` в браузере или используйте локальный сервер:

```bash
python -m http.server 8000
# или
npx serve
```
